# Обзор функциональности приложения "Motel"

Это приложение для управления бронированием в мотеле или хостеле, предназначенное для использования на стационарном терминале или планшете. Оно обладает многофункциональным интерфейсом для создания и управления бронированиями, а также функциями безопасности и администрирования.

## Основные функции

### 1. Пошаговый процесс бронирования
Приложение проводит пользователя через интуитивно понятный пошаговый процесс для создания нового бронирования:
- **Выбор корпуса:** Сначала выбирается здание или корпус.
- **Выбор типа номера:** Затем осуществляется выбор типа комнаты (например, "общий", "приватный").
- **Выбор номера/места:** Пользователь может выбрать конкретный номер или койко-место.
- **Ввод данных гостя:** Для ввода ФИО гостя используется специальная экранная клавиатура.
- **Выбор категории и периода:** Указывается категория бронирования и даты заезда/выезда.
- **Дополнительные услуги:** Есть возможность добавить к бронированию дополнительные товары или услуги.
- **Оплата:** Выбирается метод оплаты (например, СБП) и инициируется процесс платежа.
- **Подтверждение:** В конце отображается экран с подтверждением успешного бронирования или сообщением об ошибке.

### 2. Безопасность и доступ
- **Экран блокировки:** При запуске и после периода бездействия (до моего вмешательства) приложение отображает экран блокировки для защиты от несанкционированного доступа. Разблокировка производится жестом "потяни для разблокировки".
- **Динамический фон:** Фоновые изображения на экране блокировки могут динамически загружаться с сервера, что позволяет менять внешний вид.

### 3. Административные функции
- **Скрытый вход для администратора:** В приложении предусмотрен неочевидный способ входа в административную панель. Он активируется через пятикратное нажатие на часы на экране блокировки, после чего открывается экран `AdminLoginScreen`.

## Технические особенности
- **Платформа:** Приложение создано с использованием фреймворка Flutter, что позволяет ему работать на различных платформах (Android, iOS, Web, Desktop).
- **Интерфейс:** Используется пакет `Cupertino`, который стилизует элементы интерфейса под iOS.
- **Взаимодействие с сервером:**
  - **HTTP API:** Для большинства операций (загрузка настроек, данных для бронирования) используется `ApiClient`.
  - **WebSockets:** Для операций, требующих связи в реальном времени (например, отслеживание статуса платежа), используется `WebSocketService`.
- **Локализация:** Интерфейс полностью локализован для русского языка, включая форматы дат и текста.
- **Управление состоянием:** Используется BLoC (`BookingCubit`) для управления состоянием в процессе бронирования.
